# Cocínalo!

Aplicación móvil comunitaria que apoya la alimentación diaria de estudiantes, adaptándose a la disponibilidad de ingredientes y recursos de cada usuario.

## Descripción

**Cocínalo!** permite explorar recetas y descubrir qué preparar con los ingredientes que tienes en casa. Su objetivo es facilitar la planificación de comidas, fomentar el aprovechamiento de los alimentos disponibles y promover el intercambio de recetas dentro de una comunidad.

## Funcionalidades

* **Explorar recetas:** descubrir distintas preparaciones para las comidas del día.
* **Buscar recetas por ingredientes:** encontrar opciones según los ingredientes disponibles en casa.
* **Despensa personal:** gestionar los ingredientes que tiene cada usuario.
* **Comunidad:** compartir y descubrir recetas.
* **Favoritos:** guardar recetas de interés para consultarlas posteriormente.
* **Información de recetas:** consultar ingredientes, instrucciones e imágenes de las preparaciones.

## Tecnologías utilizadas

* **React Native:** desarrollo de la aplicación móvil.
* **Expo:** entorno de desarrollo y herramientas para ejecutar la aplicación.
* **Supabase:** base de datos y servicios de backend.

## Base de datos

El proyecto utiliza **Supabase** para almacenar y gestionar la información de la aplicación.

## Objetivo del proyecto

Facilitar el acceso a ideas de comidas prácticas y fomentar una alimentación más accesible, flexible y colaborativa, aprovechando los recursos disponibles de cada estudiante.
